# AI Painter App

This is a simple Python application built with Tkinter that allows you to type an idea and generates an image based on that idea using the free Pollinations AI API.

## Installation

Before running the application, you need to install the required dependencies.

1.  Make sure you have Python installed on your system.
2.  Open your terminal or command prompt.
3.  Navigate to the directory containing `painter_app.py`.
4.  Run the following command to install the necessary libraries (`requests` and `Pillow`):

    ```bash
    pip install -r requirements.txt
    ```

## Usage

Once the dependencies are installed, you can run the application:

```bash
python painter_app.py
```

Type your idea into the text box and click "Draw it!" to generate an image.
